# Python Starter Workspace

This room starts with a small Python example so you can run code right away.

## Files

- `main.py`: the main starter program
- `requirements.txt`: optional Python dependencies for this room

## Python Packages

- `requirements.txt`: add Python packages here, one per line

Each run creates a fresh isolated virtual environment on the server. If `requirements.txt` is present next to `main.py` or in a parent folder, those packages are installed into that temporary environment before the program starts.

This does not modify the server's global Python installation. Update `requirements.txt`, then run the program again to install the new packages.

The starter `main.py` already imports `rich`, and the starter `requirements.txt` includes it so the room runs immediately.

## Run It

Open `main.py` and use the Run button or press `Ctrl+Enter`.
